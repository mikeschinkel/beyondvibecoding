Beyond Vibe Coding

Patterns for Building Real Software with Claude Code

by Mike Schinkel 35 years building software, now shipping production work with Claude Code.

This is an unfinished book, published in the open

Almost none of what follows has been reviewed by me yet. It is drafted by AI from my own field notes — patterns I hit in production work with Claude Code — and published at this stage deliberately, because feedback now is worth more than polish later.

The title is provisional. The chapter order is provisional. Some pages contradict others. Disagreement is the most useful thing you can send me. Open an issue, or find me on LinkedIn.
